# IndraNet Context Composition Candidate

Version 0.5.0. This StdPack is a candidate specialization of Rosetta v3.0.0 for physical-world context.
It is not an assigned ROCK, a Core revision, or an accepted standards release.

The Pack combines immutable evidence, domain assertions, context revisions, purpose-scoped
projections, process previews, executable-model artifacts and prior-state-witness contracts.
Core Observation, Form, Lexeme, Concept, Frame, Conjecture, Matrix, Run, Action, ToolCall,
Evaluation and Receipt meanings are reused. Domain-specific structures use `indranet.*`.

Schemas and profiles are under `schema/` and `profiles/`. The six worked examples preserve
complete local tile graphs. `translators/` records native mappings and losses. Runtime code is
in the repository's `src/indranet/` tree; tests run from that repository root.

The restricted envelope subset matches the inspected constructor's body. This does not certify
all Core requirements. Domain quantities use decimal strings; equal-prior Conjecture fixtures use
exact quarter fractions. External native JSON remains intact in Observation.signal.

All examples are synthetic. No native service, headset, robot, safety controller or neural decoder
is asserted to have run. The public test-key Receipt proves only fixture signing mechanics.
