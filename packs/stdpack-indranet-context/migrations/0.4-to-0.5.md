# Candidate 0.4 to 0.5

Preserve the original 0.4 bytes and identities. New 0.5 companion outputs have new namespaced payload versions and CIDs. Core constructor versions remain the inspected Core value. The independently addressed native record is a new optional contract, not an in-place reinterpretation of old Tiles.

A migration must supply explicit source identity, event interval, frame, axis units, orientation or absence, quality interpretation, purpose/expiry/prohibited inference grants, branch and revision target. Do not invent unavailable fields. Missing bindings require a loss report or a deferred record. Use the old raw Observation and new native record as separate provenance-linked artifacts.

The strict parser now rejects duplicate JSON keys, overflow and unpaired surrogates. Purpose-selected views and contexts check their evidence ancestry. Old outputs produced from ambiguous input must not be silently reissued with a new timestamp. Reingest from source under a declared correction.
